# Vivekk Portfolio

Personal portfolio website for Vivekananda Singh.

## Run locally

Install the project dependencies and start the development server:

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Useful commands

```bash
npm run build
npm run start
npm run lint
npm run typecheck
```

## Site address

Set `NEXT_PUBLIC_SITE_URL` to the canonical site address before publishing so
page metadata and the sitemap use the correct URL. Without it, local development
uses `http://localhost:3000`.

## Portfolio content

Update the homepage text in `components/hero/hero.tsx`, the About page in
`app/about/page.tsx`, and add verified project details in
`components/projects/projects.tsx`.
